# The Kingstep Dance Studio

Static website for The Kingstep Dance Studio.

## Student of the Month
The homepage includes two Student of the Month photo cards. Visitors can download each displayed photo using the **Download Photo** button.

To update the section each month:
1. Replace/add photos inside `assets/student-of-month/`.
2. Open `script.js`.
3. Find `const studentOfMonth` and update `month`, `name`, `image`, and `description`.
4. Upload/deploy the site again.

The image filenames can be anything; just make sure the `image` path matches the file in `assets/student-of-month/`.

## Other site content
The site contains classes, schedule, gallery, clothing, admission, Student of the Month, ratings, advertising spaces and contact information.

The YouTube section and automatic YouTube API integration have been removed from this version.
